## Notes

- `composable` means the primitive has no single exported engine fn but is a
  trivial, documented function of primitives the engine already implements
  (e.g. `ta.change` = `close - close[1]`, `ta.crossover` = a cross of two series).
- `MISSING` rows are the honest, named gaps for the runtime/port decision:
  porting or adding them to `engine/ta.mjs` is required before those scripts can
  be mirrored natively. They are disclosed here, never silently ignored.
- Behavioural parity (does the engine *compute the same values*) is proven by the
  `engine/test.mjs` golden fixtures via `npm run indicator:parity`, not by this table.

## Runtime / port decision

**Decision: keep Pine as the reference / parity source; do NOT add a Pine
runtime.** The engine core is dependency-free (AGENTS.md), and a Pine runtime
would break that rule and the Pine↔engine parity discipline (risk #1).

To mirror the 7 script(s) that are not yet covered natively,
port the missing primitive(s) into `engine/ta.mjs` first: **dmi**.
Classify the unclassified primitive(s) in the COVERAGE table above before any
port: **barssince, hma, tr**.

Until then those scripts stay reference-only; the scripts marked `covered` may be
mirrored as native methods immediately.
